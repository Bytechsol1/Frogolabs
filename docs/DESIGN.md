# UI/UX Design System - Frigo Labs MVP

## Theme

- **Primary**: `#0F766E` (Teal 700)
- **Secondary**: `#14B8A6` (Teal 500)
- **Accent**: `#22C55E` (Green 500)
- **Background**: `#F8FAFC` (Slate 50)

## Page Components

### Login

- Logo
- Email/Password
- Login Button

### Clinic Dashboard

- **Cards**: Total Patients, Active Workflows, Completed Workflows
- **Table**: Patient, Test Type, Current Status, Last Updated

### Patient Details

- Patient Info
- Workflow Timeline
- Results
- Activity Log

### Admin Dashboard

- **Metrics**: Total Clinics, Active Workflows, Pending Results
- **Tables**: Clinics, Patients, Workflow Queue

## Responsive Design

- Breakpoints: Standard Tailwind (sm, md, lg, xl, 2xl)
